Đang kiểm tra…

Đưa plan lên cho tất cả điện thoại (làm trên máy tính)
  1. Nạp file plan ở nút “Nạp file plan” phía trên và kiểm tra cột cho đúng.
  2. Dán mã GitHub (token) ở mục Báo cáo trên web → Kết nối GitHub bên dưới (chỉ cần làm 1 lần).
  3. Bấm “Lưu plan cho tất cả điện thoại”. Điện thoại mở app sẽ tự lấy plan mới.

Báo cáo trên web

Kết nối GitHub (mã token)

Mỗi máy cần kết nối 1 lần để lưu và mở báo cáo. Trên máy tính: dán mã token, rồi bấm “Hiện mã QR” và dùng điện thoại quét để kết nối nhanh, không phải gõ mã.
